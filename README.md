# 🌐 Personal Portal & Sign-Up Web Application

A lightweight, responsive HTML5 web portal featuring a personal about section, an interactive multi-input registration form, and external social media links. Built as part of a core Web Development project to demonstrate foundational front-end concepts and form-handling techniques.

## ✨ Features

- **Personal Profile Section:** Includes a structured quick-facts overview and introduction list.
- **Interactive Sign-Up Form:**
  - Standard user detail fields (Name, Email, Mobile).
  - Single-selection radio controls for experience levels.
  - Multi-selection checkboxes for educational qualification options (B.Tech, M.Tech).
  - Dedicated multi-line feedback text area.
- **Brand Assets & Links:** Integrated corporate logo and direct visual social platform navigation links.
